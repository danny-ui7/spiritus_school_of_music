# Spiritus School of Music

Responsive Streamlit website for Spiritus School of Music.

## Run on Windows
1. Install Python 3.10 or newer.
2. Open Command Prompt in this folder.
3. Run `python -m pip install -r requirements.txt`
4. Run `python -m streamlit run app.py`

## Deploy with GitHub and Streamlit Community Cloud
1. Create a GitHub repository named `spiritus-school-of-music`.
2. Upload all files and the `assets` folder.
3. On Streamlit Community Cloud, choose the repository and set main file path to `app.py`.

## Personalize
Replace `assets/logo.png` and `assets/founder.jpg` with original high-resolution images when available. Update `PHONE` and `ADDRESS` in `app.py` if needed.

The admission form opens a pre-filled WhatsApp message for the visitor to review and send. It does not send automatically.
